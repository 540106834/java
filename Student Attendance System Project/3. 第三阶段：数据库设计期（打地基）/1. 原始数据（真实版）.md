# 原始数据格式解析

#  Raw 层

**目标：原封不动存储**

Raw 表结构（方案 B）：

```text
id          BIGINT AUTO_INCREMENT
device_sn   VARCHAR(64)  → 从 payload 提取
sn          VARCHAR(16)  → 从 payload 提取
raw_payload TEXT         → DIRM01003209000186012345678901200004567202602010759300 0A
parsed      TINYINT      → 0 未解析，1 成功，2 失败
error_msg   VARCHAR(255) → 解析错误信息
received_at DATETIME     → 接收时间
```

**说明：**

* `raw_payload` 保存整个字符串，不拆任何业务字段
* `device_sn` 和 `sn` 从 payload 提取，用于唯一索引和快速查询
* 这样做保证 **原始报文可回放 + 索引高效**

---

#  F09 包解析规则

你的示例：

```
DIRM010032090001 860123456789012 12345678 20260223153045 0 0A
```

我们拆解（按 ASCII）：

| 字段                     | 长度 | 说明                               |
| ---------------------- | -- | -------------------------------- |
| DIRM01                 | 6  | 设备类型/版本                          |
| 0032                   | 4  | 整个消息长度                           |
| 0900                   | 4  | 功能号 (F09 考勤上传)                   |
| 01                     | 2  | 序列号 SN（幂等）                       |
| 860123456789012        | 15 | 设备序列号 → device_sn                |
| 00004567202602010759300 | 22 | 包内容 → 业务字段，包括 card_id、打卡时间、操作类型等 |
| 0A                     | 2  | 校验和（可用于验证报文完整性）                  |

#  Parser 层设计

### 1️ 查询未解析的 Raw

```java
List<RawRecord> raws = rawRepository.findByParsed(0);
```

### 2️ 截取关键字段

假设 payload 是固定长度 ASCII：

```java
String payload = raw.getRawPayload();
String deviceType = payload.substring(0,6);
String pkgLength  = payload.substring(6,10);
String funcCode   = payload.substring(10,14);
String sn         = payload.substring(14,16);
String deviceSn   = payload.substring(16,31);
String content    = payload.substring(31,53);
String checksum   = payload.substring(53,55);
```

> 注意：长度可能随协议变化，需要和设备文档确认

---

### 3️ 解析业务字段

例如 F09 功能号：

```
content = 0000456720260201075930
```

可能解析规则：

| 字段         | 长度 | 描述                     |
| ---------- | -- | ---------------------- |
| card_no    | 10 | 学生卡号                   |
| event_time | 14 | 打卡时间，格式 YYYYMMDDHHMMSS |
| event_type | 1  | 0=进校 1=离校              |

解析示例：

```java
String cardNo = content.substring(0,10);
String eventTimeStr = content.substring(10,24);
LocalDateTime eventTime = LocalDateTime.parse(eventTimeStr, DateTimeFormatter.ofPattern("yyyyMMddHHmmss"));
int eventType = Integer.parseInt(content.substring(24,25));
```

---

### 4️ 入库 Attendance

```java
Attendance attendance = new Attendance();
attendance.setDeviceSn(deviceSn);
attendance.setCardNo(cardNo);
attendance.setEventTime(eventTime);
attendance.setEventType(eventType);
attendanceRepository.save(attendance);
```

### 5️ 更新 Raw 表

```java
raw.setParsed(1);
rawRepository.save(raw);
```

如果解析失败：

```java
raw.setParsed(2);
raw.setErrorMsg("解析失败原因");
```

---

# ✅ 总结设计

1. **Raw 层**：存原始报文，不拆业务字段
2. **Parser 层**：按协议拆出 device_sn、sn、card_no、event_time、event_type
3. **Attendance 层**：正式业务表
4. **幂等设计**：通过 device_sn + sn + card_no + event_time 保证不会重复
