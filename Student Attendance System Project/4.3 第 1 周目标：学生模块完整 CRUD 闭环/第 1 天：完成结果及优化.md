# 2️ Repository 支持按班级过滤

```java
public List<StudentDto> findByClassId(Long classId) {
    String sql = "SELECT id, student_no, name, class_id, status " +
                 "FROM student " +
                 "WHERE status = 1";
    
    List<Object> params = new ArrayList<>();
    if (classId != null) {
        sql += " AND class_id = ?";
        params.add(classId);
    }

    return jdbcTemplate.query(sql, params.toArray(), (rs, rowNum) ->
        new StudentDto(
            rs.getLong("id"),
            rs.getString("student_no"),
            rs.getString("name"),
            rs.getLong("class_id"),
            rs.getInt("status")
        )
    );
}
```

# 4️ Controller 层

```java
@GetMapping("/students")
public List<StudentDto> list(@RequestParam(required = false) Long class_id) {
    return studentService.getStudentsByClass(class_id);
}
```

注意：

* `@RequestParam(required = false)` → 参数可选
* 前端 / curl 可以传 class_id，不传就返回全部学生
