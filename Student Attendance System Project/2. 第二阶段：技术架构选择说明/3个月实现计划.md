#  第 1 个月：打地基（系统能跑）

主题：**功能闭环优先**

不要优化。
不要架构升级。
不要前端框架。

只要：能跑。

---

## 第 1 周：数据库 + 学生模块

###  目标

学生完整 CRUD 闭环。

### 任务

1. 建表

   * school_class
   * student

2. 后端接口

   ```
   GET /students
   POST /students
   PUT /students/{id}
   DELETE /students/{id}
   ```

3. 前端

   * 简单 HTML 表格
   * 表单提交
   * fetch 调接口

完成标志：

* 页面能新增学生
* 刷新能看到数据
* 删除能生效

这是第一块拼图 

---

## 第 2 周：卡片绑定模块

###  目标

实现学生和卡的完整生命周期。

### 任务

1. student_card 表
2. 绑定接口

   ```
   POST /students/{id}/bind-card
   ```
3. 解绑接口
4. 页面展示：

   * 当前卡
   * 历史卡

完成标志：

* 一人可绑定多次卡
* 解绑记录保存

---

## 第 3 周：考勤核心

这是系统心脏 

###  目标

刷卡 → 生成考勤记录。

新增表：

```
attendance
```

接口：

```
POST /api/checkin
```

流程：

1. 根据 card_no 查 student_card
2. 查 student
3. 写 attendance

完成标志：

* curl 模拟刷卡成功
* 数据库生成记录

---

## 第 4 周：查询 + 基础统计

### 🎯 目标

能查数据。

接口：

```
GET /attendance?class_id=1&date=2026-03-01
```

功能：

* 按班级查
* 按日期查
* 出勤人数统计

前端：

* 表格
* 简单统计数字
