# ✅ 改造后的脚本（稳定调试版）

```bash
#!/bin/bash

# ===== 固定字段 =====
HEADER="DIRM01"
LENGTH="0032"
FUNC="0900"
DEVICE_SN="860123456789012"
CHECKSUM="0A"

# ===== 参数配置 =====
COUNT=20               # 发送条数
BASE_TIME="20260226073000"  # 起始时间（yyyyMMddHHmmss）
EVENT_TYPE="0"         # 0=上学 1=放学

echo "开始生成 $COUNT 条考勤数据..."
echo "--------------------------------"

for ((i=1; i<=COUNT; i++))
do
  # SN 两位递增
  SN=$(printf "%02d" $i)

  # 卡号 00000001~00000020 循环
  CARD_NO=$(printf "%08d" $i)

  # 时间递增 10 秒
  EVENT_TIME=$(date -d "${BASE_TIME:0:8} ${BASE_TIME:8:2}:${BASE_TIME:10:2}:${BASE_TIME:12:2} +$(( (i-1)*10 )) seconds" +"%Y%m%d%H%M%S")

  # 拼接报文
  PAYLOAD="${HEADER}${LENGTH}${FUNC}${SN}${DEVICE_SN}${CARD_NO}${EVENT_TIME}${EVENT_TYPE}${CHECKSUM}"

  echo "[$i] $PAYLOAD"

  curl -s -X POST http://192.168.11.171:8080/api/raw/upload \
  -H "Content-Type: text/plain" \
  -d "$PAYLOAD" > /dev/null

  sleep 0.2
done

echo "--------------------------------"
echo "发送完成"
```

### 1️⃣ 流水号 SN

```bash
SN=$(printf "%02d" $i)
```

* **`$i`** 是循环计数器，从 `1` 到你设定的 `COUNT`（比如 20）。
* **`printf "%02d" $i`** 的意思：

  * `printf` 就像 C 语言的格式化输出，可以把数字或文字格式化成你想要的样子。
  * `%02d` 解释：

    * `%d` → 表示输出一个整数。
    * `02` → 表示如果数字不足 2 位，就在前面补 0。
  * 例子：

    ```
    i = 1 → 01
    i = 2 → 02
    i = 10 → 10
    i = 20 → 20
    ```
* 所以 `SN` 就是 **报文的序列号**，固定 2 位。

---

### 2️⃣ 卡号 CARD_NO

```bash
CARD_NO=$(printf "%08d" $i)
```

* 也是用 `printf` 来格式化，但这里是 **8 位数字**。
* `%08d`：

  * `%d` → 整数
  * `08` → 不够 8 位就在前面补 0
* 例子：

  ```
  i = 1 → 00000001
  i = 2 → 00000002
  i = 10 → 00000010
  i = 20 → 00000020
  ```
* **作用**：模拟考勤卡号，每个人卡号固定长度 8 位。

---

### 3️⃣ 事件时间 EVENT_TIME

```bash
EVENT_TIME=$(date -d "${BASE_TIME:0:8} ${BASE_TIME:8:2}:${BASE_TIME:10:2}:${BASE_TIME:12:2} +$(( (i-1)*10 )) seconds" +"%Y%m%d%H%M%S")
```

这个稍微复杂一点，拆开来看：

#### ① `${BASE_TIME:0:8}` 之类的

* `BASE_TIME="20260226073000"` → 起始时间

  * 格式：`yyyyMMddHHmmss`
* `${BASE_TIME:0:8}` → 从第 0 个字符开始，取 8 个字符 → `20260226`（年月日）
* `${BASE_TIME:8:2}` → 从第 8 个字符开始，取 2 个字符 → `07`（小时）
* `${BASE_TIME:10:2}` → 分钟 → `30`
* `${BASE_TIME:12:2}` → 秒 → `00`

#### ② 拼成日期字符串

```bash
"${BASE_TIME:0:8} ${BASE_TIME:8:2}:${BASE_TIME:10:2}:${BASE_TIME:12:2}"
```

* 结果：`20260226 07:30:00`
* 这是 `date` 命令可以识别的时间格式。

#### ③ `+$(( (i-1)*10 )) seconds`

* `$((...))` → Bash 里的数学运算
* `(i-1)*10` → 每条记录时间增加 10 秒

  * 第一条 i=1 → `(1-1)*10 = 0` 秒 → 07:30:00
  * 第二条 i=2 → `(2-1)*10 = 10` 秒 → 07:30:10
  * 第三条 i=3 → `(3-1)*10 = 20` 秒 → 07:30:20
* `+N seconds` → `date` 命令会在基础时间上加 N 秒。

#### ④ `+"%Y%m%d%H%M%S"`

* 这是 `date` 命令的输出格式：

  * `%Y` → 年（2026）
  * `%m` → 月（02）
  * `%d` → 日（26）
  * `%H` → 小时（07）
  * `%M` → 分钟（30）
  * `%S` → 秒（00/10/20…）
* 最终结果就是 `20260226073000`、`20260226073010`、`20260226073020` …

### ✅ 总结

| 变量           | 格式             | 示例                               |
| ------------ | -------------- | -------------------------------- |
| `SN`         | 2位流水号          | 01, 02, …, 20                    |
| `CARD_NO`    | 8位卡号           | 00000001, 00000002 …             |
| `EVENT_TIME` | yyyyMMddHHmmss | 20260226073000, 20260226073010 … |

**核心逻辑**：

1. 每条数据 SN 自动递增
2. 卡号从 1 开始，前面补 0 到 8 位
3. 事件时间以起始时间为基础，每条增加 10 秒
