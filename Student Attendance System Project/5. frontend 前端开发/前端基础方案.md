我们可以先从 **原生 HTML + CSS + JS** 打好基础，再平滑升级到 **Vue 3**，这样你既能理解前端原理，又能快速实现最小可用前端查询模块。

我帮你规划一个 **循序渐进路线**：

---

## **阶段 0 – 前端基础打底**

### 1️ HTML

* **目的**：结构化展示内容
* **内容**：

  * 标签：`<div>`, `<table>`, `<tr>`, `<td>`, `<input>`, `<button>`
  * 表单元素：`<select>`, `<option>`, `<input type="date">`

### 2️ CSS

* **目的**：美化页面
* **内容**：

  * 颜色、边框、内外边距、字体
  * 表格样式、按钮样式、下拉框样式

### 3️ JavaScript

* **目的**：动态交互
* **内容**：

  * 绑定点击事件：`button.onclick = function(){…}`
  * 获取表单值：`document.querySelector('select').value`
  * Ajax 请求后端数据：`fetch('/api/attendance?…')`
  * 动态生成表格内容：`innerHTML` 或 `createElement`

---

## **阶段 1 – 最小可用 HTML+JS 查询页面**

```html
<!DOCTYPE html>
<html>
<head>
  <meta charset="UTF-8">
  <title>考勤查询</title>
  <style>
    body { font-family: Arial; margin: 20px; }
    table { border-collapse: collapse; width: 100%; margin-top: 20px; }
    th, td { border: 1px solid #ccc; padding: 8px; text-align: center; }
    select, input, button { padding: 5px; margin-right: 10px; }
  </style>
</head>
<body>
  <h2>考勤查询</h2>
  <select id="classSelect"></select>
  <input type="date" id="dateInput">
  <button id="queryBtn">查询</button>

  <table id="resultTable">
    <thead>
      <tr>
        <th>学号</th><th>姓名</th><th>进次数</th><th>出次数</th>
      </tr>
    </thead>
    <tbody></tbody>
  </table>

  <script>
    const classSelect = document.getElementById('classSelect')
    const dateInput = document.getElementById('dateInput')
    const queryBtn = document.getElementById('queryBtn')
    const tbody = document.querySelector('#resultTable tbody')

    // 初始化班级下拉
    fetch('/api/classes')
      .then(res => res.json())
      .then(data => {
        data.forEach(c => {
          const option = document.createElement('option')
          option.value = c.id
          option.textContent = c.name
          classSelect.appendChild(option)
        })
      })

    // 查询考勤
    queryBtn.onclick = () => {
      const classId = classSelect.value
      const date = dateInput.value
      fetch(`/api/attendance?class_id=${classId}&date=${date}`)
        .then(res => res.json())
        .then(data => {
          tbody.innerHTML = ''  // 清空表格
          data.forEach(r => {
            const tr = document.createElement('tr')
            tr.innerHTML = `<td>${r.student_no}</td><td>${r.student_name}</td>
                            <td>${r.in_count}</td><td>${r.out_count}</td>`
            tbody.appendChild(tr)
          })
        })
    }
  </script>
</body>
</html>
```

 这样你就有了一个 **纯原生前端的最小可用查询页面**：

* 可以选择班级和日期
* 点击查询就显示考勤数据
* 完全不依赖 Vue，理解 HTML/JS/CSS 的基础逻辑

## **阶段 2 – 升级到 Vue 3**

一旦你熟悉了原生的逻辑，就可以升级到 Vue 3：

* 用 **组件化** 替代原生 DOM 操作
* 用 **`v-for`** 渲染表格
* 用 **`v-model`** 双向绑定表单
* 用 **axios** 或 **fetch** 调用后端

优势：代码更简洁，可维护性更高，未来扩展（分页、搜索、报表）会很方便。
