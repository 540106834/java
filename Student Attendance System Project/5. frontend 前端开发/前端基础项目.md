#  二、对接 API（班级列表）

假设你的接口：

```
GET /api/classes
```

## JS

```js
async function loadClasses() {
  const res = await fetch("/api/classes");
  const data = await res.json();

  let html = `
    <h2>班级列表</h2>
    <table border="1" cellpadding="8">
      <thead>
        <tr>
          <th>ID</th>
          <th>年级</th>
          <th>班级名称</th>
        </tr>
      </thead>
      <tbody>
  `;

  data.forEach(c => {
    html += `
      <tr>
        <td>${c.id}</td>
        <td>${c.grade}</td>
        <td>${c.name}</td>
      </tr>
    `;
  });

  html += "</tbody></table>";

  document.getElementById("app").innerHTML = html;
}
```

点击“班级管理”，就会调用后端。

这一刻，你的前后端已经真正连上。

#  三、学生列表（带参数）

后端接口：

```
GET /api/students?classId=1
```

JS：

```js
async function loadStudents(classId = 1) {
  const res = await fetch(`/api/students?classId=${classId}`);
  const data = await res.json();

  let html = `
    <h2>学生列表</h2>
    <table border="1" cellpadding="8">
      <thead>
        <tr>
          <th>ID</th>
          <th>姓名</th>
          <th>学号</th>
        </tr>
      </thead>
      <tbody>
  `;

  data.forEach(s => {
    html += `
      <tr>
        <td>${s.id}</td>
        <td>${s.name}</td>
        <td>${s.studentNo}</td>
      </tr>
    `;
  });

  html += "</tbody></table>";

  document.getElementById("app").innerHTML = html;
}
```

后面可以改成点击班级 → 加载对应学生。
