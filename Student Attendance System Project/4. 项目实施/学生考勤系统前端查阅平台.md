好，来把“学生考勤系统前端查阅平台”这件事拆开讲清楚。

你现在做的是 smart_attendance，对吧？
那这个“前端查阅平台”本质上是一个：

> 给老师 / 管理员 / 家长查看考勤数据的 Web 控制台

它不是炫技型前端，而是一个“数据展示型后台系统”。

而这种后台系统，80% 都是用 Vue.js 做的。

---

#  一、这个平台要解决什么问题？

从业务角度看，它至少要做 4 件事：

1. 查询学生出勤记录
2. 按日期 / 班级 / 学号筛选
3. 展示统计数据（迟到率、缺勤率）
4. 导出报表

它的定位更像：

> 数据可视化终端 + 管理后台

而不是营销官网。

---

#  二、系统结构长什么样？

你现在的整体架构可以这样：

```text
设备 → 后端 (Spring Boot)
           ↓
        MySQL
           ↓
       前端 Vue
           ↓
         Nginx
```

部署上是：

```text
Vue build → 生成 dist/
dist/ → 放到 nginx html 目录
nginx 反向代理 /api → Spring Boot
```

这个结构非常标准。

#  五、权限与部署重点（运维视角）

这是你要特别关注的点：

### 1️ 跨域问题

开发环境：

* vite 代理

生产环境：

* nginx 反向代理

---

### 2️ 打包优化

```
npm run build
```

生成：

```
dist/
  assets/
  index.html
```

你要理解：

* 静态资源缓存
* hash 文件名
* gzip 压缩

---

### 3️ nginx 配置关键点

```nginx
location / {
    try_files $uri $uri/ /index.html;
}

location /api/ {
    proxy_pass http://backend:8080/;
}
```

这个是 Vue 单页应用的核心。
