# **Java 集合框架（List、Set、Map）** 和 **泛型（Generics）** 的概念、特点、应用以及示例。

## 1 Java 集合框架概览

Java 集合框架主要分 **三类接口**：

| 接口       | 描述        | 常用实现类                                              |
| -------- | --------- | -------------------------------------------------- |
| **List** | 有序，可重复    | `ArrayList`, `LinkedList`, `Vector`                |
| **Set**  | 无序，不可重复   | `HashSet`, `LinkedHashSet`, `TreeSet`              |
| **Map**  | 键值对映射，键唯一 | `HashMap`, `LinkedHashMap`, `TreeMap`, `Hashtable` |

集合框架主要特点：

* 提供统一接口 (`Collection` / `Map`)
* 可存储对象（引用类型）
* 支持泛型（类型安全）

---

## 2 List：有序可重复

**特点**：

* 元素按插入顺序排列
* 可以根据索引访问
* 可重复

**示例（泛型）**：

```java
import java.util.ArrayList;
import java.util.List;

public class ListDemo {
    public static void main(String[] args) {
        List<String> names = new ArrayList<>(); // 泛型指定存储 String
        names.add("Alice");
        names.add("Bob");
        names.add("Alice"); // 可重复

        // 遍历
        for (String name : names) {
            System.out.println(name);
        }

        // 根据索引访问
        System.out.println("第1个元素: " + names.get(0));
    }
}
```

---

## 3️ Set：无序不可重复

**特点**：

* 元素不重复
* 无索引（无法通过下标访问）
* 常用于去重

**示例**：

```java
import java.util.HashSet;
import java.util.Set;

public class SetDemo {
    public static void main(String[] args) {
        Set<Integer> numbers = new HashSet<>();
        numbers.add(1);
        numbers.add(2);
        numbers.add(1); // 重复元素被忽略

        for (Integer num : numbers) {
            System.out.println(num); // 输出顺序不固定
        }
    }
}
```

* **TreeSet**：元素有序（自然排序或自定义 Comparator）
* **LinkedHashSet**：保持插入顺序

---

## 4️ Map：键值对集合

**特点**：

* 键唯一，值可重复
* 根据键快速访问值
* 常用于缓存、查找表

**示例**：

```java
import java.util.HashMap;
import java.util.Map;

public class MapDemo {
    public static void main(String[] args) {
        Map<String, Integer> scores = new HashMap<>();
        scores.put("Alice", 90);
        scores.put("Bob", 85);
        scores.put("Alice", 95); // 覆盖之前的值

        // 遍历 Map
        for (Map.Entry<String, Integer> entry : scores.entrySet()) {
            System.out.println(entry.getKey() + ": " + entry.getValue());
        }

        // 获取值
        System.out.println("Alice 的成绩: " + scores.get("Alice"));
    }
}
```

* **LinkedHashMap**：保持插入顺序
* **TreeMap**：键排序

---

## 5️ 泛型（Generics）

**作用**：

* 提高类型安全，避免 `ClassCastException`
* 编译时检查类型，减少强制类型转换
* 可用于集合、方法、类

**示例：集合中的泛型**：

```java
List<String> list = new ArrayList<>();
list.add("hello");
String s = list.get(0); // 不需要强转
```

**示例：泛型方法**：

```java
public class Utils {
    public static <T> void printArray(T[] array) {
        for (T item : array) {
            System.out.println(item);
        }
    }
    
    public static void main(String[] args) {
        Integer[] nums = {1, 2, 3};
        String[] names = {"Alice", "Bob"};
        printArray(nums);
        printArray(names);
    }
}
```

**示例：泛型类**：

```java
public class Box<T> {
    private T value;

    public void set(T value) { this.value = value; }
    public T get() { return value; }

    public static void main(String[] args) {
        Box<String> box = new Box<>();
        box.set("Hello");
        System.out.println(box.get());
    }
}
```

---

## 6️ 总结

| 接口   | 特点           | 常用实现                      | 泛型用途          |
| ---- | ------------ | ------------------------- | ------------- |
| List | 有序、可重复       | ArrayList, LinkedList     | 保证元素类型一致，安全访问 |
| Set  | 无序、不可重复      | HashSet, TreeSet          | 去重，保证类型安全     |
| Map  | 键唯一、值可重复     | HashMap, TreeMap          | 键值对类型安全       |
| 泛型   | 编译期类型检查、减少强转 | List<T>, Map<K,V>, 泛型方法/类 | 增强类型安全、可复用性   |

---

 **实战经验**：

1. `ArrayList`：频繁随机访问
2. `LinkedList`：频繁插入/删除
3. `HashSet`：快速去重
4. `TreeSet` / `TreeMap`：需要排序
5. **泛型**：尽量给集合加上类型，减少强转错误
